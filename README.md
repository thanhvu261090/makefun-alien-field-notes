An alien tourist's one-line review of planet Earth, left after a short visit.

> "Earth review: the locals pay rent to sleep indoors, drink bean juice to stay awake, and stare at glowing rectangles for fun. 2/5 — but the sunsets nearly saved it."

## How it works

`main.py` holds the entry line as a constant, checks it against the kit's gate (UTF-8 text, 1–200 characters, not only whitespace, a single line with no control characters or padding), and writes it to `/output/entry.txt` when run with `python3 main.py`.
